# frontend/assets — изображения

Фото взяты с сайта компании **KASKAD** (kaskad-n.ru) по договорённости:
только проекты **Каскад Парк, Академия Парк, Федоскино Парк, Парк Апрель**
и **общие фоны без названий проектов**. Логотипы и названия других посёлков
НЕ использовались.

> Изображения сжаты (JPEG, ширина ≤ 1280px), чтобы не раздувать репозиторий.

## Назначение файлов

| Файл | Используется | Источник (проект) |
|------|--------------|-------------------|
| `bg_01.jpg` | hero-фон главного экрана | общий фон |
| `bg_02.jpg` … `bg_12.jpg` | запасные фоны | общие фоны без названий |
| `kaskad_park_1.jpg` | карточка «Каскад Парк» | Каскад Парк |
| `kaskad_park_2.jpg` | запасной | Каскад Парк |
| `kaskad_park_3.jpg` | — (не используется) | Каскад Парк |
| `kaskad_park_4.jpg` | запасной | Каскад Парк |
| `kaskad_park_5.jpg` | — | Каскад Парк |
| `akademiya_park.jpg` | карточка «Академия Парк» | Академия Парк |
| `fedoskino_park_1.jpg` | карточка «Федоскино Парк» | Федоскино Парк |
| `fedoskino_park_2.jpg` | запасной | Федоскино Парк |
| `park_april_1.jpg` | карточка «Парк Апрель» | Парк Апрель |

## Как используются в `frontend/app.py`

- `PROJECTS_SHOWCASE` — список карточек посёлков (имя + ссылка на файл).
- `render_hero()` — фоновое фото `bg_01.jpg`.

## Что проверить вам (я не вижу изображения)

Сопоставление «файл → проект» выведено из структуры страницы сайта и может
требовать ручной проверки глазами. Если какое-то фото не то — замените файл
(сохранив имя) или поправьте путь в `frontend/app.py`.

> ⚠️ Пока перепроверьте, что на фото не видно названий/логотипов посёлков
> кроме разрешённых четырёх, — при необходимости замените.
